# 온나 라이브 교실 · ONNA LIVE

온나에듀랩(ONNA EDU LAB) 수업용 **올인원 교실 인터랙션 웹앱**.
학생은 로그인 없이 번호+이름만으로 입장하고, 선생님은 한 화면에서 채팅·즉석 퀴즈·작품 투표·소감을 운영합니다.

- **앱 주소**: https://leeyoungui.github.io/onna-live/
- **기본 수업 방**: `bongmyeong-1119` (봉명중 3학년 AI 캐릭터 수업, 2026-11-19)
- 다른 수업은 주소 뒤에 `?room=방이름`만 붙이면 됩니다. 예) `?room=gwandong-microbit`

## 🏛️ 3D 전시관 (3교시)

티처빌 「우리반 전시회」처럼 아바타가 걸어 다니며 작품을 감상하는 메타버스 전시실. **별도 회원가입·앱 설치 없이** 3교시 화면에서 바로 입장합니다.

- **작품 자동 배치**: Firestore `works` 를 실시간으로 읽어 벽면·가벽 **액자 32개**에 자동으로 걸립니다(제목·작성자 이름표 포함). 입구에서 들어서면 중앙 가벽 앞면부터 3점씩 보입니다. 학생이 업로드하는 즉시 액자가 채워집니다.
- **아바타**: 입장 시 색 8종 · 모자 6종(야구모자/비니/리본/꽃/왕관) 선택, 머리 위에 번호·이름 표시. `👕` 버튼으로 언제든 변경.
- **조작**
  - PC: `W A S D` / 방향키 이동, `Shift` 달리기, 마우스 드래그로 시점 회전, `V` 시점 전환, `Esc` 나가기
  - 모바일·태블릿: 좌측 하단 **가상 조이스틱** 이동 + 화면 드래그로 시점 회전
  - **1인칭 / 3인칭** 전환 버튼 (우측 상단 `🧍 3인칭` / `👤 1인칭`)
- **소통**: 👋 손흔들기 · 👏 박수 · ❤️ 하트 리액션(머리 위로 이모지가 떠오름). 액자에 다가가면 작품명 카드가 뜨고, 액자를 클릭/탭하면 **작품 상세 모달**에서 크게 보기 · 하트 · **칭찬 댓글** 남기기.
- **포토존**: 안쪽 모자이크 벽 앞 러그 위에 서면 `📸 포토존 찰칵` 버튼이 뜹니다. 누르면 아바타가 만세 포즈를 하고, 전시관 제목·학생 이름·날짜가 찍힌 **PNG 기념사진**을 내려받습니다(아이폰은 사진을 길게 눌러 저장). 길을 찾기 어려우면 `📸 포토존 가기` 를 누르면 아바타가 포토존까지 걸어갑니다.
- **다자 동시 접속**: 같은 방 학생들의 아바타 위치·방향·이모지를 `rooms/{room}/galleryPeers/{peerId}` 로 동기화합니다.
  - Firestore 무료(Spark) 한도 절약: **2초 간격 + 실제로 움직였을 때만** 쓰기, 가만히 있으면 20초 하트비트, 나가면 문서 삭제, 45초 이상 갱신 없는 친구는 화면에서 숨김.
- **저사양 대비**: 3교시 상단 `📋 목록으로 보기` 로 언제든 즉시 목록 갤러리로 복귀합니다(WebGL 미지원 기기에서는 자동 안내).

### 무료 한도 참고 (Spark)

| 항목 | 무료 한도 | 이 앱의 사용량 감각 |
|---|---|---|
| 쓰기 | 20,000/일 | 16명 × 40분 수업에서 아바타 동기화 포함 대략 3,000~8,000회 |
| 읽기 | 50,000/일 | 친구 아바타 1건 갱신이 접속 인원수만큼 읽힘 → **한 반 30명 이상이거나 하루 여러 반**이면 읽기가 먼저 소진될 수 있음 |
| 저장 | 1GB | 작품 1점 ≈ 100KB → 16명 × 3점 ≈ 5MB |

> 한도가 걱정되면 3D 전시관 대신 `📋 목록으로 보기` 로 수업하고, 전시관은 감상 5~10분만 쓰는 것을 권장합니다.

## 기술 메모

- 정적 단일 파일 `index.html` (Firebase SDK·QR 라이브러리·**Three.js r157** 인라인 포함 → 외부 CDN 의존 없음, 학교 네트워크에서 CDN 차단 걱정 없음)
- 3D 전시관은 `index.src.html` 안의 `Hall` 모듈(Three.js WebGL). 방·액자 32개·아바타·조명은 모두 코드로 생성(외부 3D 모델 파일 없음), 화면 캡처는 `preserveDrawingBuffer` 로 처리
- 빌드: `python3 build.py` → `vendor/*.js` 를 `index.src.html` 의 `<!--__THREE__-->` 등 자리표시자에 인라인해 `index.html` 생성
- **Firestore Database만 사용** (Storage 미사용 → 무료 Spark 요금제로 동작)
- 작품 이미지는 브라우저 `<canvas>`에서 가로 최대 720px, JPEG 품질 0.72부터 자동 조정하여 약 100KB 이하 base64로 문서에 직접 저장
- 방 분리: `rooms/{room}` 문서(채팅 잠금·퀴즈·캔바 링크·전시관 제목) + 하위 컬렉션 `messages`, `works`(+`comments` 하위), `reflections`, `galleryPeers`
- GitHub Pages(`main` 브랜치 루트)로 배포

## Firestore 준비 상태

프로젝트 `onna-live`에 **Firestore 데이터베이스가 만들어져 있어야** 실시간 기능이 동작합니다.
콘솔 → 데이터베이스 및 스토리지 → Firestore → 데이터베이스 만들기 → 위치 `asia-northeast3(서울)` → 테스트 모드로 시작.
